## 复用的历史原始证据

这些为本项目私人实测摘要；不随源码分发日志、存档、样本、权重、反编译材料或私人路径。真实性复核使用本地产物，外部用户需用自己的合法材料复现。

- 一段连续的 157 输入跨幕轨迹，157 个接受/送达/稳定后继，0 拒绝；157 前置决策、最终后继和 19 个重点结算点的机械比较一致。77 次 Mac 拖牌存在 end_turn 可用性时机差异，**严格 GUI 决策时机不一致**。起点为第一幕 15 层的 Continue 夹具，止于第二幕首战药水奖励，不是整局/完整第二幕保真。
- 最小学习闭环：20 个真实战斗示范、8 次实际参数更新、第 4→8 次在新进程恢复模型/优化器/RNG/采样顺序、两局独立冻结评估。8 次更新均改变参数；不同 minibatch 的 loss 不构成胜率改善证据。本次仅核对旧样本、更新记录、checkpoint 与评估产物，未重跑旧训练。
- 有限复杂机制调试结果包括 Bound、污染/Spiral、Ethereal/降级、Wither、背击、Escape、知识恶魔和假人事件的部分分支。调试有强制遭遇/注入/999 格挡干预且退出身份检查失败，**不属于本版正常宿主验收**。另一分支、无保护扣血、占卜等不能声称已通过。

## 变更与明确限制

- 将日期实验实现整合为单份 `src/host`；保留原 API 调用、正常身份检查和隔离，参数化游戏/profile/工具链/workspace。继续使用固定原 release 的可追踪 ELF 派生，不发行该二进制。
- 新局与 Continue 显式区分；原 selector/progression 普通复制，不合成解锁。新局路径复用历史通过实现并在本版编译；**本次新增真实运行只覆盖 Continue 短段**。
- 合并 card-state-v2 观察及实例双射、选牌显示重排比较。活动药水弹窗查询排除原对象已经标记移除的实例；编译通过，本次短段未触发多弹窗场景，不能称作 Mac 原生修复已验证。
- 完整 raw Mac 导入遇到旧未归属 next_act、未知 UI 输入等会明确失败。历史专项 157 输入转换没有被变成自动兜底。
- 本次仅 Linux x86_64/profile 2 实测。路径可移植不等于任意系统/编译器都受支持；guard 依赖固定编译结果，其他构建需单独审查。
- 玩家 SL、跨进程游戏恢复、全机制/全局保真、HPC、稳定 RL 和大规模训练均延期。游戏退出资源/语言/遥测等诊断保留在私有日志；不将未分类诊断自动解释为已修复。
