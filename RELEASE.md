# v0.1.1-alpha

Original-engine tooling for ML/RL workflows in Slay the Spire 2.

## Changes

- English and Simplified Chinese guides for Linux policy integration, Mac human demonstrations, replay, and the observation/action protocol.
- A runnable trajectory-reading example with a synthetic observation, action, and successor.
- Contribution guidance and a bilingual issue form.

Linux runtime code remains at v0.1.0-alpha. This release reuses the v0.1.0-alpha Mac recorder package, with recorder revision 0.2.3. Replay behavior follows the [current replay guide](docs/REPLAY.md).
